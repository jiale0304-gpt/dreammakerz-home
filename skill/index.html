同样用 AI，结果差很远 // THE PROBLEM

新人 A 跟 AI 说：「帮我写一篇房产贴文。」AI 回给他：

「这是一个优质项目，交通便利，环境优美……」

写给谁的？卖点是什么？跟别人写的有什么不一样？全部没有。

问题不在 AI，在我们给它的东西太少。下面 5 个技能，每个都附完整 prompt，复制过去把【】的地方填好，结果马上不一样。

怎么用（真的很简单） // HOW TO USE

1

按 COPY 复制 prompt

COPY

FILL

5 个完整 prompt，按一下 copy // THE PROMPTS

01

交代清楚

SKILL 01

AI 写得空泛，通常是我们没讲清楚。每次都交代 5 样东西：角色、对象、资料、要求、格式。少了「对象」，AI 只能写给所有人，等于没写给任何人。

PROMPT · 交代清楚 · 万用模板
你是【角色，例如：新山房地产 agent】。
请帮我写一篇【内容类型，例如：IG 贴文 / WhatsApp 讯息 / email】，给【对象：谁、在哪里、什么情况】看。

资料（只用以下资料，不要自己补）：
- 【卖点 1】
- 【卖点 2】
- 【价格 / 面积 / 位置等，我已经核实过】

要求：【语气，例如：轻松、像朋友聊天】，不要用【不想出现的字眼，例如：夸张形容词】。
格式：【字数】字内，【结构，例如：开头一句钩子，结尾问一个问题】。
填好的例子：你是新山房地产 agent。请帮我写一篇 IG 贴文，给在新加坡上班、准备买第一间房的年轻夫妻看。资料：2 房，走路约 10 分钟到 RTS 站。语气轻松，150 字内，结尾问一个问题。
02

先问再挑刺

SKILL 02

AI 默认会顺着你讲。开始前叫它先问你问题，写完叫它挑毛病，两段可以分开用。

PROMPT · 开始之前 · 加这段
在开始之前，先问我 3 个问题，确认你需要哪些资料。
等我回答之后，你再开始写。
PROMPT · 写完之后 · 加这段
现在用【对象，例如：第一次买房的年轻夫妻】的角度，看你刚才写的内容：
1. 指出最弱的 3 个地方，说明为什么。
2. 再给我一个改好的版本。
如果你觉得我原本的方向有问题，直接告诉我，不用客气。
03

乱资料变表

SKILL 03

发展商资料、群组讯息、自己的笔记，一次丢进去。「还缺什么」那一栏最有用，见客户之前就知道要先问发展商什么。

PROMPT · 乱资料变表 · 卖点 / 证据 / 还缺什么
把以下资料整理成一个表格，三栏：
卖点 / 证据（资料里哪里写的）/ 还缺什么资料。

规则：
- 只用我提供的资料，资料里没有的不要自己补，写「资料没有」。
- 价格、面积、日期照资料原文写，不要换算或估算。

表格之后，列出我应该先问发展商的 5 个问题。

资料：
【贴上发展商资料、群组讯息、你自己的笔记】
04

跟 AI 练对话

SKILL 04

叫 AI 扮演一个还在犹豫的客户，你练习回答。真的见客户时，这些问题你已经答过一次了，不会临场脑空。

PROMPT · 跟 AI 练对话 · 客户角色扮演
你现在扮演一个客户：【客户背景，例如：在新加坡上班、第一次买房、预算有限】，
对【项目 / 户型】有兴趣，但还在犹豫。

规则：
1. 一次只说一两句话，等我回答再继续。
2. 提出真实客户会问的问题，例如：价钱、贷款、地点、什么时候买比较好。
3. 不要太容易被说服。
4. 我说「结束」的时候，停止扮演，然后：
   - 给我 3 个具体的改进建议
   - 指出我哪一句回答最好、哪一句最需要改，并给我改好的说法

现在开始，你先开口。
05

Prompt 库

SKILL 05

每天重复做的工作，不要每次重新想。让 AI 帮你写成固定模板，存在手机 Notes 或 AI 的项目功能里，用完改一点，越用越顺。

PROMPT · Prompt 库 · 帮你写自己的模板
帮我整理一套我自己的常用 prompt。

我每天重复做的工作是：
1. 【例如：写项目贴文】
2. 【例如：回复客户 WhatsApp 询问】
3. 【例如：看房后的 follow-up 讯息】

请为每一件工作写一个可以重复使用的 prompt，
每个都包含五个部分：角色、对象、资料、要求、格式。
需要我每次自己填的地方，用【】标出来。

框里的内容比较长的话可以往下滑。

这 5 个技能用在哪里 // WHERE TO USE

01 · 交代清楚

项目贴文、文案、email

任何要 AI 帮你写东西的时候，先把角色、对象、资料、要求、格式讲清楚。

02 · 先问再挑刺

提案、回复客户、重要讯息

越重要的内容越要它挑毛病。让它先站在客户的角度看一次，你再发出去。

03 · 乱资料变表

Sales Kit、项目学习

新项目一出来，资料一大堆。先整理成表，卖点和资料缺口一眼看清楚。

04 · 跟 AI 练对话

Calling、看房、谈价

见客户前花 10 分钟练一轮，「我再考虑看看」这种话就不会接不住。

05 · Prompt 库

每日工作、团队 SOP

把每天重复的事写成模板，自己用，也可以分享给团队一起用。

!! · 记住

AI 不会替你核实资料

价钱、面积、政策、贷款条件，一定要对照官方资料，自己查清楚再发给客户。

明天要见客户，两种准备方式 // BEFORE / AFTER

情况：明天要见一对第一次买房、在新加坡上班的年轻夫妻。

没用这 5 个技能

  • 贴文写得跟别人差不多
  • 资料一大堆，不知道还缺什么
  • 客户说「我再考虑」，当场接不住
  • 每次都从头想要怎么问 AI

用了之后

  • 贴文有对象、有卖点，改一下就能发
  • 先列好要问发展商的问题
  • 已经跟 AI 练过一轮对话
  • 常用 prompt 存好，拿来就用
✓

用法提醒：这 5 个 prompt 在 ChatGPT、Claude、Gemini 都能用。第一次照抄，用几次之后按你自己的习惯改，效果会越来越好。
