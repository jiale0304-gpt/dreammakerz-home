    PROMPT · 买房总开销计算机
    

    

    请帮我做一个「买房总开销计算机」网页，直接在对话里显示，手机打开也好用。
用简体中文，金额写成 RM 加千位逗号（例如 RM450,000）。
这是马来西亚 New project（发展商新盘）版本。

【输入】
1. SPA 价
2. 发展商 discount（可选 RM 或 %）
3. 发展商 rebate（可选 RM 或 %）
4. 贷款成数滑杆（50% 到 90%）
5. 「银行按 SPA 价 / 按 nett price 批贷」切换，默认按 nett price
6. 「律师费和印花税按 SPA 价 / 按 nett price 算」切换，默认按 SPA 价
7. 勾选：发展商承担 SPA 律师费 / MOT 印花税 / 贷款律师费 / 贷款印花税
8. 「首次购屋豁免」开关
9. 利率滑杆（2% 到 8%）、年限滑杆（5 到 35 年）

【Discount 和 Rebate 是两回事，一定要分开算】
- Discount：直接扣房价。nett price = SPA 价 减 discount，银行按 nett price 批贷。
  例子：RM500,000 discount 10%，nett price RM450,000，贷 90% 是 RM405,000，顾客头期 RM45,000。
- Rebate：房价不变，nett price 还是 SPA 价，银行照原价批贷，rebate 只拿来抵头期（各发展商、银行做法不同，以确认为准）。
  例子：RM500,000 rebate 10%，贷 90% 是 RM450,000，原本头期 RM50,000，rebate RM50,000 抵掉，实付头期 RM0。
- Rebate 比头期多的话，多出来的部分不抵其他费用，明细里写清楚多出多少。

【计算规则】
- 头期 = nett price 减贷款额，最少是 0；有 rebate 再扣，最少还是 0
- MOT 印花税分级：头 RM100,000 收 1%，接下来 RM400,000 收 2%，接下来 RM500,000 收 3%，超过 RM1,000,000 的部分收 4%
- 贷款印花税：贷款额的 0.5%
- 律师费（SPA 按房价算，贷款按贷款额算）：头 RM500,000 收 1.25%（最低 RM500），之后收 1%
- New project 律师费折扣，上面的结果再乘：不超过 RM50,000 固定 RM500；不超过 RM250,000 乘 75%；不超过 RM500,000 乘 70%；不超过 RM1,000,000 乘 65%；超过 RM1,000,000 乘 50%
- 首次购屋开关打开，而且房价不超过 RM500,000：MOT 和贷款印花税都算 0
- 发展商承担的项目算 RM0，明细里注明「发展商承担」
- 月供用等额本息公式

【显示】
- 最上面一张固定的卡片，大字显示「入门要准备的现金」（头期加所有费用）和「每月供」
- 费用明细清单和合计；有 rebate 时分开写：原本头期、rebate 抵头期、实付头期
- 一份报价单文字，加「复制」和「WhatsApp 发送」按钮
- 底部写明：利率以银行批核为准，律师费以律师报价为准（未含服务税和杂费），只供参考

任何输入一改，全部数字即时更新。

    这句指令每一部分在做什么 // BREAKDOWN
    
    
    
      
    01 · 规则写清楚
    不让 AI 自己猜
    印花税和律师费的分级直接写进指令，Claude 照着算，不会用旧资料或自己编数字。
    
      
    02 · 附例子
    Discount 和 rebate 分开
    两种优惠影响的地方不一样。指令里各附一个例子，AI 就不会混在一起算。
    
      
    03 · New project
    律师费打折
    受 Housing Development Act 管制的住宅新盘，律师费有另一个比较低的收费表。发展商承担的费用勾一下就扣掉。
    
      
    04 · 首次购屋豁免
    一个开关就算好
    符合条件的首次购屋，MOT 和贷款印花税直接算 0，顾客马上看到省了多少。
    
      
    05 · 一键复制
    报价单直接发
    整份明细变成一段文字，复制后贴到 WhatsApp，顾客马上看到。
    
      
    !! · 记住

    指令最后叫它用一个例子测试，对照我们的答案（RM19,563 / RM69,563 / RM1,992），对了才用。
